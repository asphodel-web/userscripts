Duolingo Full Course Viewer

See how much of your current course there really is and how much you've already done, the course structure, what lessons there will be, etc. This is pretty bare bones and extracts the course data. It allows you to download the course data in a json file to do with as you wish. This is the same source of data used by services like duolingodata.com.
